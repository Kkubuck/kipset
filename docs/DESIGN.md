# KIPSET Design Direction

KIPSET uses an editorial, performance-first visual system: near-black surfaces, off-white type, and red reserved for active anatomy, destructive actions, and finish states. The interface avoids decorative gradients and excessive cards so the athlete can identify the next action from a distance.

## Product principles

1. **One dominant action per screen.** Workout detail prioritizes Start; the timer prioritizes Complete Round; results prioritize Save Story.
2. **Progressive disclosure.** Home shows today, weekly totals, favorites, and recent sessions. Scaling, equipment, sources, data tools, and safety detail live where they are needed.
3. **Native, readable type.** The stack uses Segoe UI Variable on Windows and native system/CJK fallbacks elsewhere. Body text is 14/20, compact metadata never drops below 11px, and headings use semibold weights.
4. **Spacing expresses relationships.** A four-pixel spacing ramp groups related controls and creates larger pauses between sections.
5. **Motion explains change.** Short ease-out fades and state transitions acknowledge navigation, round completion, and results. Reduced-motion settings remove nonessential animation.
6. **Color is information.** White is action and hierarchy; neutral gray is structure; warm red communicates primary muscle emphasis and risk. Color is never the only status signal.
7. **Local and calm.** No feed, engagement bait, or dashboard metric exists without a direct training decision attached to it.

## Reference standards

- [Apple Human Interface Guidelines: Typography](https://developer.apple.com/design/human-interface-guidelines/typography)
- [Apple Human Interface Guidelines: Accessibility](https://developer.apple.com/design/human-interface-guidelines/accessibility)
- [Microsoft Fluent 2: Typography](https://fluent2.microsoft.design/typography)
- [Microsoft Fluent 2: Layout](https://fluent2.microsoft.design/layout)
- [Microsoft Fluent 2: Motion](https://fluent2.microsoft.design/motion)

The anatomy view borrows the useful convention—not the artwork—of distinguishing primary and secondary muscle involvement, as documented by [Muscle & Motion](https://www.muscleandmotion.com/strength-training-app/) and muscle heat-map products such as [Fitbod](https://help.fitbod.me/hc/en-us/articles/360004429814-How-Fitbod-Creates-Your-Workout). KIPSET's anatomy artwork and classifications are original.
